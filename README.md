# Game Engines – Unreal Engine 5 (C++)

Coursework for the *Motores Gráficos* subject of the Master's Degree in Video Game Design and Development (UOC).

## Features

- Third-person character with Enhanced Input, camera and C++ AnimInstance
- Free Mixamo character with its animations
- Interactable door (interface + line trace) and push trigger (overlap)
- Hitscan shooting with line tracing
- Static enemies with health that are destroyed when it runs out
- Animated portal (material) that teleports the player

## Controls

| Key | Action |
|---|---|
| WASD | Move |
| Mouse | Camera |
| Space | Jump |
| Left click | Shoot |
| E | Interact |

## Opening the project

Unreal Engine 5.8. Open `GameEnginesUOC.uproject` and accept rebuilding the modules.
